# 公开内容与隐私边界

公开版本采用MIT许可证，包含应用源码、迁移、合成测试、独立部署说明与离线CI。第三方依赖仍遵循各自许可证。

原始产品调研截图、DOM文本、真实账号对话、私人部署历史、云端凭据、模型采集结果和工具工作目录不属于公开内容。私有开发仓库保留这些资料；公开仓库从经检查的当前工作区快照开始，不复制其.git历史。不要直接把私有仓库改为public。

在backend运行：

```bash
uv run python infra/export_public.py /绝对路径/尚不存在的公开目录
```

导出使用白名单，拒绝符号链接、超大文件及已识别的凭据/个人邮箱/私人部署地址；任何命中都会在写入前停止并只报告文件路径。文件清单与SHA-256写入PUBLIC_EXPORT.json，供核对。扫描不是完整的个人信息识别或授权审查；公开前仍需复核新增内容。快照不会自动创建Git历史、提交、建立GitHub仓库、推送或公开。

导出后在新目录重复前后端离线检查、检查README链接和配置，再自行建立首次提交并创建公开仓库。维护者需启用GitHub Private vulnerability reporting，并确认自己的品牌、截图和素材公开范围。

AI服务会接收本轮任务需要的提示词、已授权上下文与证据；语音转写会向配置的服务发送音频。LangSmith默认关闭，开启后还有追踪外发。历史和摘要只用于理解，不能替代当前业务读取或用户确认。模型费用由部署者承担，请保持账号配额及安全验证开启。
