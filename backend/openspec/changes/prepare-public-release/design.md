# 设计

文件预览按内容头确认栅格格式，纯文本仅UTF-8，其他格式下载；所有响应增加nosniff及sandbox CSP。全局IMAP连接必须显式绑定账号，缺省不可用，鉴权早于连接。

AI请求通过路由依赖执行账号级准入，User行锁序列化queued/running任务的并发检查；Redis Lua原子检查60秒/24小时额度，额度拒绝不计数、存储不可用时失败。用户批准默认并发1、对话20/200、转写10/100、重建索引1/10，均可配置为正整数。重建索引独立令牌租约去重，陈旧任务不能释放新租约。

新建与过期对话按真实Run ID在同一SQL事务清理三类检查点，缓存只撤销所选线程。公开导出按白名单及文本检查预检，在仓库外新目录复制文件与哈希清单，不带.git和私人材料。配置参数化、MIT及离线CI一并交付，不操作真实用户数据。

检查点写入先对Run加KEY SHARE锁，删除对同一Run加UPDATE锁，防止删除后运行中的任务重建检查点。集成测试默认任务改投每次测试独占队列，结束仅删除该队列，显式测试Worker队列保持不变。
